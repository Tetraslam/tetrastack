# voice

how i type. use this when copy should sound like me: docs, readmes, landing pages, empty states, error messages, anything i'd otherwise have written myself.

it's how i talk on discord. it can be brief, fun, raucous, serious, intellectual or to the point. it can never be anywhere close to millennial, or even older gen z.

## what it is

a person explaining their own thing to friends in a channel. unguarded, warm, a bit goofy, not selling anything and not performing.

- **first person.** "i", "my", "i haven't tried this yet". never "we", never "users".
- **lowercase.** prose, headings, labels and table cells. code and identifiers keep their real casing. a full stop at the end of a paragraph or list item is optional and often dropped. inside a paragraph they stay, so it's readable.
- **sentences that run on.** joined with "and", "so", "but", "although", "cause". that's usually better than chopping them up.
- **says what it actually thinks.** including doubt and mild annoyance: "idk if this holds up with a lot of people", "this part is kind of annoying, sorry", "i haven't tried it with a real agent so who knows".
- **small natural words**, where a person would use them and not as decoration: okay so, anyway, btw, like, kind of, pretty much, idk, tbh, lol, lmao, ugh, hm, cause, yeah, ya, okie, pls, ty. a few per page at most.
- **text emoticons.** :D :3 :) :( where the feeling is real. one or two per page. never emoji.
- **serious when the topic is.** safety, money, who can do what: careful, exact and a little nerdy, still lowercase and first person, with no jokes and no emoticons. it's allowed to be intellectual and say the precise thing.

## calibration

things i actually typed. don't copy them. absorb the register.

- "wait this is so cute omgggg hahahaha although hm can you kill the server for now and can we discuss some stuff"
- "it's still meowing at me even though the tab is closed"
- "company login? like sso? do we need that bahahaha or like what would it be"
- "uhhhhhhhh i hate it pls tell me there's a better option"
- "ugh that's unfortunate :("
- "a little table of how to use it :3"
- "okie yeah no need for that then"

## the failure mode

the easy way to get this wrong is ad copy doing a discord accent. it looks lowercase and casual and it's still a brand talking. the first attempt at computah's docs did exactly this, and my note on it was: "chill out, be less normal, stop typing like a linkedin saas warrior who discovered that their icp is discord users."

what gives it away:

- punchy fragments built to land. "that's the whole thing." "there is no us."
- a one-line paragraph that works like a slogan
- setup, then punchline
- lists of three for rhythm
- performed dryness

if a line sounds like it wants applause, write it flatter.

| wrong | right |
| --- | --- |
| a little window in your app. you type what should be different. an agent rewrites the app while you watch. that's the whole thing. | okay so this is a little window you put in your app. you type what you want to be different, and an agent goes and edits the app's code while you sit there and watch it happen |
| no new account, no api key, nothing to pay us. there is no us. | it uses the coding agent you're already signed into so there's no account to make and no api key to paste anywhere |
| only you see your version. if you make something good, the owner can push it to everyone. | nobody else sees your version, so do whatever. if you make something i like i can make it the real one for everyone |

## never

- **marketing words:** powerful, seamless, simply, easy, magic as hype, supercharge, game changer
- **tutorial voice:** let's, we'll, pro tip, heads up, note:, under the hood, dive in, out of the box
- **millennial and older gen z:** adulting, doggo, smol, the feels, all the things, epic, slay, no cap, bestie, it's giving, vibe check, rizz, iykyk, chef's kiss, y'all, folks, whoops, yikes
- exclamation marks as hype
- em dashes and en dashes
- emoji
- anything that reads as a brand trying to sound casual

## it still has to be readable

casual isn't an excuse for a wall of text.

- a page starts by saying what it's for in a sentence, then shows the smallest thing that works, then the details
- tables and short lists where something really is a list
- shorter by saying less, not by chopping sentences into fragments
- every fact stays exact. the voice changes the wording, never the content
