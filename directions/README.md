# directions

one file per direction from [taste.md](../taste.md#directions). each lists primary sources: the real thing (archives, original works, canonical pages, frame galleries, the designer's own writing), and what an interface should take from each.

agents: after picking a direction in the brief, open its file, visit and screenshot every source, and build from those, not from memory. `status: draft` means unreviewed, so treat it as a lead and verify. `status: approved` means curated.

links only. no copyrighted images live in this repo.

## format

```md
---
direction: <name>
status: draft | approved
---

# <name>

<one line: what it is, what it fits>

## sources
- [<what it is>](<url>): <what to take, concretely>

## avoid
<the generic cliché agents produce from memory>
```
