# raw text

the content is the design. markdown, mono, a cursor. fits products for machines and agents.

## sources
- [Pierre Computer Company’s corporate site, presented as a compact, monospaced text document](https://pierre.computer/): Build hierarchy with uppercase section labels, blank lines, short lists, and visible link syntax. Keep the content small enough that its entire structure is apparent without navigation chrome.
- [John Gruber’s original Markdown project page, including links to its plain-text source](https://daringfireball.net/projects/markdown/): Compare rendered prose with the source document. Headings, indentation, and punctuation should remain intelligible without decorative containers.
- [CERN’s preserved first-website project page](https://info.cern.ch/hypertext/WWW/TheProject.html): Use descriptive links as the primary navigation system; group them with short explanations. Preserve natural document flow and browser-native behavior. This is a structural ancestor, not a monospace specimen.

## on the web
- [Fabien Sanglard's site on graphics and software engineering](https://fabiensanglard.net/): a narrow column, a chronological index, modest headings, minimal navigation. a very high ratio of information to visual machinery.
- [Pierre Computer Company, the corporate site as a markdown document](https://pierre.computer/): uppercase section labels, blank lines, short lists, and visible link syntax. the whole structure is visible without navigation chrome.

## avoid
Green-on-black hacker theatrics, fake command prompts, and typewriter animations around ordinary company copy.
