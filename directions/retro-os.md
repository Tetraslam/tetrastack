# retro os

windows, bevels, pixel icons, a menu bar. fits playful tools, personal sites, nostalgia.

## sources
- [original System 7.0 screenshots covering Finder, settings, menus, and dialogs](https://guidebookgallery.org/screenshots/macos70): study striped title bars, thin outlines, patterned fills, compact typography, and clear active-window distinctions. Preserve the Macintosh menu-bar model rather than mixing it with Windows conventions.
- [original Windows 95 screenshots, including applications, dialogs, setup, and shutdown](https://guidebookgallery.org/screenshots/win95): study gray control surfaces, directional bevels, blue active title bars, inset fields, and tight spacing. Raised and sunken edges must consistently communicate whether something can be pressed or edited.
- [browser-accessible emulation collection of historical Macintosh systems](https://infinitemac.org/): interact with menus, window dragging, selection, and overlapping documents. Reference actual behavior and component proportions, not just desktop wallpaper and icons.
- [working Windows 98-inspired desktop implemented for the web](https://98.js.org/): study how desktop windows, taskbar state, menus, and familiar applications work together in a browser. Use it as a web adaptation, while keeping Windows 95 versus 98 details explicit.

## avoid
random floating gray windows, decorative close buttons, and modern padding inside fake vintage chrome.
