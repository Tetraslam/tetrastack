# evangelion / nerv

emergency orange and red on black, hexagonal panels, condensed warning type, a heavy mincho for titles, system readouts. fits monitoring, ops, anything with alarms. see also title card.

## sources
- [frame-by-frame original episode sequence showing emergency displays, illuminated status panels, and graphs](https://wiki.evageeks.org/FGC:Episode_02_Scene_07a): inspect cuts 243 onward for repeated warning cells and the contrast between huge emergency labels and compact telemetry. Use repetition to communicate escalation, with color changes tied to actual states.
- [EvaWiki's MAGI article, with original frames of the MAGI displays](https://wiki.evageeks.org/Magi): study the three-part system diagram, angular boundaries, large node names, and subordinate technical labels. Give topology meaning: each region should represent a real subsystem or decision.
- [original Jet Alone control-room frames, including password entry, errors, and danger indicators](https://wiki.evageeks.org/FGC:Episode_07_Scene_09): compare ordinary data display with the abrupt takeover by a large error message. Use restrained operational screens so exceptional warnings can genuinely dominate.
- [official NERV Disaster Prevention app website, showing a real information-dense warning interface](https://nerv.app/en/): study legible maps, explicit severity labels, large countdowns, and selective alert colors. This is a useful practical counterweight to fictional screens: urgency must improve recognition.
